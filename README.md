\# ⚡ OmniFit — Next-Gen Wearable Intelligence \& Gym Trainer



OmniFit is an offline-first, high-octane athletic training assistant and physical strain engine designed for Android. It blends professional-grade biomechanical telemetry tracking, local smart-device virtualization, and reactive fitness splits into a fluid, highly-polished experience utilizing modern Material 3 and Jetpack Compose.



\---



\## ✨ Features



\### 🎬 High-Fidelity Cinematic Splash

\*   \*\*Synchronized Initialization:\*\* A custom choreographed 5-second cinematic startup routine that warms up local AI database layers, calibrates vital metric aggregators, and pre-allocates physical strain parameters smoothly.

\*   \*\*Strobe \& Shake Feedback:\*\* Physics-based camera-shake offsets and ambient particle effects that respond as core fitness telemetry layers lock in.



\### 🎨 Adaptive Dual-Theme Engine (Light \& Dark)

\*   \*\*High-Octane Visuals:\*\* Optimized using a centralized adaptive lookup palette (`VoltLime`, `SportsTeal`, `FlameOrange`, and `DarkSpaceCharcoal`) ensuring clean, high-contrast, and deeply readable interfaces across both light and dark themes. No faded or washed-out labels!

\*   \*\*Fluid Transitions:\*\* Seamless visual coordinate morphs matching the user's active system preferences without performance stutter or lag.



\### 🏋️ Active Telemetry \& Strain Diagnostics

\*   \*\*Live Workout Tracker:\*\* Track active sets, reps, and workloads with dedicated safety constraints, instant pause/discard overrides, and real-time athletic session calculations.

\*   \*\*Smart Device Virtualization:\*\* Emulates real-time heart rate GATT sensors and BLE device connections (such as simulated Whoop or custom fitness bands) directly within the app.

\*   \*\*Adaptive Period Care Mode (🌸):\*\* Dynamically adjusts recommended training volume, joint-load metrics, and exercise selections depending on active metabolic parameters.



\### 🗄️ Architecture \& Performance Core

\*   \*\*100% Kotlin \& Jetpack Compose:\*\* Declarative UI containing custom animations and optimized state parameters to prevent unnecessary recompositions.

\*   \*\*Robust Room Local Persistence:\*\* Fully populated SQLite database layers for keeping records of workout templates, daily metabolic logs, and personal metrics.

\*   \*\*MVVM Clean Architecture:\*\* Clean separation of concerns between raw DAOs, repository sync layers, and view state engines (`FitnessViewModel`).



\---



\## 🛠️ Tech Stack \& Architecture



\*   \*\*UI Framework:\*\* \[Jetpack Compose](https://developer.android.com/jetpack/compose) with Material Design 3.

\*   \*\*Data Persistence:\*\* \[Room Database](https://developer.android.com/training/data-storage/room) (SQLite) with custom relational mappings.

\*   \*\*State Management:\*\* StateFlow \& SharedFlow with Lifecycle-aware collectors (`collectAsStateWithLifecycle`).

\*   \*\*Concurrency:\*\* Kotlin Coroutines \& Flow API for non-blocking asynchronous data pipelines.

\*   \*\*Dependency injection:\*\* Constructor Injection pattern for clean, decoupled architectures.

\*   \*\*Animations:\*\* Compose transition systems (`Animatable`, `spring`, `keyframes`, and `infiniteRepeatable`).
